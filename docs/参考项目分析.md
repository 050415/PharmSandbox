# SumGNN 与 DDI-AltRec 参考项目分析

## 📊 项目一：SumGNN (⭐91, Bioinformatics 2021)

### 项目概述
**论文**: "SumGNN: Multi-typed Drug Interaction Prediction via Efficient Knowledge Graph Summarization"
**核心思想**: 通过知识图谱摘要技术，使用图神经网络预测多种类型的药物相互作用

### 核心算法流程
```
输入: 药物对 (drug_A, drug_B)
        ↓
1. 子图提取: 从知识图谱中提取k-hop子图 (默认3跳)
        ↓
2. 节点标注: 为子图中的节点添加位置标签
        ↓
3. RGCN编码: 使用关系图卷积网络编码子图
        ↓
4. 子图聚合: Sum/MLP/GRU聚合器汇总信息
        ↓
5. 关系分类: 预测药物对之间的交互类型
        ↓
输出: DDI类型 (如: 增强/抑制/代谢竞争等)
```

### 关键代码片段
```python
# RGCN模型核心 (rgcn_model.py)
class RGCN(nn.Module):
    def __init__(self, params):
        # 节点嵌入
        self.embed = nn.Parameter(torch.Tensor(self.num_nodes, self.emb_dim))
        # 聚合器选择
        if params.gnn_agg_type == "sum":
            self.aggregator = SumAggregator(self.emb_dim)
        # 多层GNN
        self.layers = nn.ModuleList()
        i2h = self.build_input_layer()  # 输入层
        for idx in range(self.num_hidden_layers - 1):
            h2h = self.build_hidden_layer(idx)  # 隐藏层
```

### 核心功能模块

#### 1. DDI检测 (interaction.py)
```python
# 药物交互数据库 (硬编码示例)
MEDICATION_INTERACTIONS = {
    ('warfarin', 'aspirin'): {
        'severity': 'severe',
        'description': 'Increased risk of bleeding.'
    },
    ('lisinopril', 'potassium'): {
        'severity': 'severe',
        'description': 'May cause dangerous increase in potassium levels.'
    },
    # ... 更多交互
}

# 检测逻辑
def check_medication_interaction(med1_name, med2_name):
    """检查两种药物是否有已知交互"""
    if (med1_name.lower(), med2_name.lower()) in MEDICATION_INTERACTIONS:
        return MEDICATION_INTERACTIONS[(med1_name, med2_name)]
    return None
```

## 🎯 两个项目的对比与整合建议

### 技术栈对比
| 维度 | SumGNN | DDI-AltRec |
|------|--------|------------|
| **核心算法** | GNN (RGCN) | 规则匹配 |
| **DDI检测** | 预测未知交互 | 查询已知交互 |
| **数据格式** | 知识图谱三元组 | 药物对字典 |
| **扩展性** | 可泛化到新药 | 依赖硬编码数据库 |
| **前端** | 无 | React |
| **后端** | Python脚本 | Flask API |

### 整合方案 (你的PharmSandbox)
```
┌─────────────────────────────────────────────────────────────┐
│                    PharmSandbox 架构                         │
├─────────────────────────────────────────────────────────────┤
│ 感知层 (Perception)                                          │
│   ├─ NER: drug_names.tsv → 药物ID归一化                      │
│   └─ 参考: DDI-AltRec的药物名称匹配逻辑                       │
├─────────────────────────────────────────────────────────────┤
│ 决策层 (Decision)                                            │
│   ├─ GNN DDI推演: SumGNN的RGCN模型                           │
│   │   └─ 输入: DrugCentral分子结构 + TWOSIDES训练标签         │
│   ├─ 风险评分: SIDER副作用概率 + MIMIC-IV约束                 │
│   └─ 替代药推荐: ATC树搜索 + 指南约束                         │
├─────────────────────────────────────────────────────────────┤
│ 行动层 (Action)                                              │
│   ├─ API: 参考DDI-AltRec的Flask架构                          │
│   ├─ 前端: 参考DDI-AltRec的React + 雷达风险图                 │
│   └─ 报告: 生成推演报告 + 续方草稿                            │
└─────────────────────────────────────────────────────────────┘
```

### 建议的开发顺序
1. **Phase 1**: 复用SumGNN的GNN模型，用TWOSIDES数据训练
2. **Phase 2**: 参考DDI-AltRec的API设计，构建后端接口
3. **Phase 3**: 扩展风险评分逻辑 (整合SIDER + MIMIC-IV)
4. **Phase 4**: 实现替代药推荐 (ATC树 + 适应症匹配)
5. **Phase 5**: 开发前端UI (React + 雷达风险图)
