# MIMIC-IV 数据集

## 状态：💰 购买中

## 获取方式
1. 注册 PhysioNet 账号: https://physionet.org/content/mimiciv/
2. 完成 CITI 伦理培训 (约2小时)
3. 签署数据使用协议
4. 下载数据

## 需要的文件
- `mimiciv/` - 主数据集
- `hosp/` - 医院数据 (诊断、检验、用药)
- `icu/` - ICU数据 (生命体征、用药记录)

## 在课设中的作用
功能②：患者特异性病理生理约束
- 提供真实患者的年龄、疾病史、化验值
- 作为沙盘推演的动态变权因子
- 例如：肌酐清除率极低 → 肾毒性权重调高
